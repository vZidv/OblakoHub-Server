# OblakoHub Server

Сервер собственного облака для OblakoHub на C# и ASP.NET Core (.NET 10). Хранит файлы и данные подключения в каталоге данных. Передача файлов идёт потоково.

## Локальный запуск

Установите Docker и откройте терминал в корне репозитория. Соберите образ:

```sh
docker build -t oblakohub-server:dev .
```

Запустите сервер:

```sh
docker run -d --name oblakohub-server -p 127.0.0.1:8080:8080 -v oblakohub-data:/data oblakohub-server:dev
```

Адрес API — `http://127.0.0.1:8080`. Команда `docker logs oblakohub-server` выводит одноразовый код при первом запуске. Он действует 15 минут. До первого подключения перезапуск контейнера выдаёт новый код. Держите журналы установки в закрытом доступе.

## Подключение и проверка

1. Вызовите `GET /api/v1/health`. Ответ содержит версию API.
2. Отправьте `POST /api/v1/pair` с JSON `{"code":"КОД"}`. Ответ содержит `token`. Сохраните его в защищённом месте. Код после обмена недействителен.
3. Передавайте токен в заголовке `Authorization: Bearer <token>` при запросах к файлам.

| Запрос | Действие |
| --- | --- |
| `GET /api/v1/files?path=Папка` | Список элементов. Для корня опустите параметр. |
| `POST /api/v1/files/folder?path=Папка` | Создать папку. |
| `PUT /api/v1/files/content?path=Папка/файл.png` | Загрузить файл. Тело запроса содержит байты файла. |
| `GET /api/v1/files/content?path=Папка/файл.png` | Скачать файл. |
| `POST /api/v1/files/move` | Переместить или переименовать. JSON содержит поля `from` и `to`. |
| `DELETE /api/v1/files?path=Папка/файл.png` | Удалить файл или пустую папку. |

Пути относительны корню. Вложенные сегменты разделяются символом `/`. Кодируйте значения query-параметров при отправке. Запись поверх существующего файла возвращает конфликт.

## Доступ с другого устройства

Оставьте HTTP-порт привязанным к loopback. Для LAN или интернета настройте HTTPS через обратный прокси или защищённую приватную сеть. В качестве адреса используйте доступный клиенту URL. Для домашнего сервера за CGNAT обычно нужен туннель или приватная сеть. Не публикуйте порт HTTP с токенами в интернете.

## Данные и состояние проекта

Том `oblakohub-data` нужно сохранять при пересоздании контейнера и включать в резервные копии. Сервер поддерживает одно подключение. Для сброса доступа остановите сервер, удалите только `credentials.json` из каталога данных и запустите его снова. Старый токен перестанет действовать, файлы останутся.

Сейчас реализован серверный API. Опубликованный образ, мастер SSH и провайдер в настольном OblakoHub ещё предстоит подключить.
