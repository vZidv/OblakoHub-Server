OblakoHub Server — программа, которая превращает твой VPS в личное облако. Файлы хранятся на твоём сервере, а в OblakoHub ты видишь их рядом с файлами из других облаков.

Выбрать способ установки ↓
Где в OblakoHub найти «Собственное облако»?
Выбери режим установки

1Подготовка данных

Для собственного облака понадобится сервер. Можно арендовать VPS — это виртуальный компьютер в интернете, на котором будут храниться ваши файлы.

После аренды откройте письмо от хостинга или панель управления VPS. Для подключения понадобятся три вещи.

  • IP-адрес сервера — публичный IPv4, указанный хостингом.
  • Пользователь SSH — логин для входа на сервер, часто это root.
  • Пароль для этого пользователя. Если вы настраивали вход по SSH-ключу, подготовьте свой приватный ключ.

Доступ из интернетаЕсли в панели хостинга включён сетевой экран, убедитесь, что он разрешает входящие подключения по TCP на порты 80 и 443. Они нужны установщику для настройки HTTPS и доступа к облаку.

2Запуск установки

Откройте приложение OblakoHub.

  1. Нажмите «Добавить облако» и выберите «Собственное облако».
  2. Придумайте название, например «Мой личный сервер», и выберите «Установить на VPS».
  3. Введите IP-адрес сервера и пользователя SSH из первого шага. В поле «Пароль или приватный ключ» введите пароль или вставьте содержимое файла приватного ключа.
  4. Нажмите «Установить облако».

При первом подключении OblakoHub покажет отпечаток SSH-ключа сервера. Это короткая строка, по которой можно убедиться, что клиент подключается именно к вашему VPS. Сверьте её с отпечатком в консоли VPS у хостинга. Если они совпадают, нажмите «Доверять и установить». Дальше приложение само настроит сервер.

3Выбор объёма облака

После установки появится раздел «Место для облака». Выберите, сколько места на сервере смогут занять ваши файлы.

  • «Задать лимит» — оставьте рекомендованный объём или укажите свой в гигабайтах.
  • «Без лимита» — облако сможет занять всё свободное место на диске. Если диск заполнится, серверу и другим приложениям может не хватить места для работы.

Завершите подключение. В боковой панели OblakoHub появится облако с названием, которое вы выбрали на втором шаге.

1Установи Docker и Git

Для этих команд подойдёт VPS с Ubuntu и публичным IPv4. В панели хостинга открой входящие TCP-порты 80 и 443, затем открой терминал VPS.

Терминал на VPS
wget -O install-docker.sh https://raw.githubusercontent.com/vZidv/OblakoHub-Server/main/install-docker.sh &&
bash install-docker.sh
Если на VPS нет wget

Скачай и запусти тот же скрипт через curl.

Терминал на VPS
curl -fLo install-docker.sh https://raw.githubusercontent.com/vZidv/OblakoHub-Server/main/install-docker.sh &&
bash install-docker.sh

2Запусти сервер

Терминал на VPS
git clone https://github.com/vZidv/OblakoHub-Server.git &&
cd OblakoHub-Server &&
bash install.sh

Для подключения Введи IPv4 по запросу. Дождись строк Адрес подключения и Одноразовый код (15 минут). Обе понадобятся в приложении.

Если код истёк

До первого подключения снова выполни bash install.sh в папке проекта.

3Подключи облако в OblakoHub

Открой в клиенте Добавить облако → Собственное облако → Готовый сервер.

Введи название, адрес сервера и одноразовый код. Нажми Проверить сервер.

Код действует 15 минут. Когда появится раздел Место для облака, выбери лимит и заверши подключение.

Открой своё облако

Найди его по выбранному названию в боковой панели OblakoHub. Нажми «Загрузить» и выбери первый файл. Он появится в списке и будет храниться на твоём сервере.

Как это устроено

Клиент OblakoHub

На твоём компьютере. Показывает файлы с VPS рядом с другими облаками и отправляет команды серверу.

HTTPS · API

OblakoHub Server

На твоей VPS. Работает в Docker, хранит файлы в постоянном томе и отдаёт их клиенту по запросу.

При автоматической установке клиент настраивает VPS по SSH. После подключения работа с файлами идёт по HTTPS.
