OblakoHub Репозиторий на GitHub ↗

Запусти своё облако

Храни файлы на своём компьютере или VPS и открывай их в OblakoHub.

Где будет работать облако?

1. Подготовь компьютер

Установи Git и запусти Docker Desktop. Если на Linux уже установлен Docker Engine, можно использовать его.

Терминал на компьютере
git clone https://github.com/vZidv/OblakoHub-Server.git
cd OblakoHub-Server

2. Запусти сервер

В том же терминале выполни команды по порядку. После первой дождись окончания сборки. Когда увидишь код в журнале, нажми Ctrl+C, чтобы выйти из просмотра. Сервер останется запущен.

Терминал на компьютере
docker build -t oblakohub-server:dev .
docker run -d --name oblakohub-server -p 127.0.0.1:8080:8080 -v oblakohub-data:/data oblakohub-server:dev
docker logs -f oblakohub-server

Адрес сервера — http://127.0.0.1:8080. Если код истёк до подключения, выполни docker restart oblakohub-server и снова открой журнал.

1. Установи Docker и Git

Открой терминал VPS с Ubuntu 24.04 LTS через SSH или в панели хостинга. Подготовь публичный IPv4 и разреши входящие TCP-подключения на порты 80 и 443 в панели хостинга.

Терминал на VPS
wget -O install-docker.sh https://raw.githubusercontent.com/vZidv/OblakoHub-Server/main/install-docker.sh &&
bash install-docker.sh

Понадобится wget или curl. Если wget недоступен, скачай скрипт командой curl -fLo install-docker.sh URL, подставив ссылку из блока.

2. Запусти сервер

Терминал на VPS
git clone https://github.com/vZidv/OblakoHub-Server.git &&
cd OblakoHub-Server &&
bash install.sh

Когда установщик спросит, введи публичный IPv4 из панели VPS. Он выведет HTTPS-адрес и одноразовый код. Если код истёк до подключения, снова выполни bash install.sh в папке проекта.

Подключи облако в OblakoHub

Открой Добавить облако → Собственное облако → Готовый сервер. Введи название, адрес сервера и одноразовый код, затем нажми Подключить.

Код действует 15 минут и используется один раз.
